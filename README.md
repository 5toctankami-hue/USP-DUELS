# USP Duels: сайт с аккаунтами и онлайн 1 на 1

Это отдельный сайт. Регистрация, вход, сохранение прогресса, рейтинг и комнаты 1 на 1 работают на вашем сервере и не зависят от claude.ai.

## Запуск у себя на компьютере

Нужен Node.js 18 или новее. Устанавливать пакеты не надо.

```
cd usp-duels-site
node server.js
```

Откройте http://localhost:3000, зарегистрируйтесь и играйте.

## Как играть с другом через интернет

Сайт нужно выложить так, чтобы он был доступен по ссылке. Два простых пути.

**Быстро, без хостинга.** Запустите сервер у себя и откройте к нему доступ через туннель, например `cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000`. Друг открывает выданную ссылку, регистрируется, вы оба вводите один код комнаты. Пока ваш компьютер выключен, сайт недоступен.

**Постоянно.** Подойдёт любой хостинг для Node.js (Render, Railway, Fly.io, свой VPS). Настройки:

- команда запуска: `node server.js`
- переменная `PORT` берётся из окружения хостинга автоматически
- HTTPS нужен обязательно, и хостинги его выдают сами (иначе пароли идут по сети открытым текстом)

## Где лежат данные

Все аккаунты и сохранения лежат в файле `data/db.json`. На бесплатных тарифах диск часто стирается при каждом перезапуске, поэтому подключите постоянный диск (volume) и укажите путь переменной `DATA_FILE`, например `DATA_FILE=/data/db.json`. Если этого не сделать, аккаунты пропадут при перезапуске.

Необязательно: переменная `SECRET` задаёт ключ подписи токенов. Если её нет, ключ создаётся сам и хранится в `db.json`.

## Что внутри

- `server.js`: HTTP, аккаунты, сохранения, рейтинг и WebSocket-комнаты
- `public/index.html`: сама игра с экраном входа
- Пароли хранятся хешами (scrypt с солью), вход ограничен по числу попыток с одного IP
- В комнате максимум два игрока, имя игрока в матче берётся из аккаунта, подделать его нельзя

## Что важно знать

- Попадания считает клиент стрелка, а не сервер. Для игры с друзьями этого хватает, но защиты от читеров нет.
- Сервер проверяет форму сохранения и отбрасывает несуществующие скины, но количество монет и кейсов принимает от клиента.
- Файловая база рассчитана на небольшое число игроков (сотни). Для большего нужна настоящая база данных.
